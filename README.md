# yousif4business-collab.github.io

Personal portfolio of **Yousif Abdulkareem Al-Sara**, IT infrastructure and operations engineer in Baghdad.

**Live:** https://yousif4business-collab.github.io

- One static page (`index.html`) in English and Arabic: a language button switches the whole page, including right-to-left layout. Arabic link: https://yousif4business-collab.github.io/?lang=ar
- No build step, no frameworks, no trackers, no third-party requests.
- Animated network hero drawn on a canvas, client and equipment logo belts, an experience timeline, filterable case work with project popups, software projects, an automation flow, process, FAQ and WhatsApp contact.
- Respects reduced-motion settings; works on phones.
- Fonts: Sora, Inter and Readex Pro (Arabic), self-hosted under the SIL Open Font License (`fonts/`).
